## 🎵 Adding Your Special Song
1. Copy your romantic song file into the `audio/` folder.
2. Rename it to **`our-song.mp3`**.
3. When Ankita clicks **"🎵 Play Our Song"**, it will play your song!
*(Note: If no mp3 is present, the website automatically plays a soothing, gentle romantic music-box melody using the Web Audio API so it sounds enchanting right out of the box!)*

## ⏳ Changing the Anniversary Start Date
If you ever want to adjust the anniversary counter, open **`script.js`** and edit line 17:

